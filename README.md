# cgjunghelpdesk.github.io

Shareable episode links for the Jung Helpdesk iOS app.

- `/e/NNN` (optionally `?t=seconds`) opens the episode in the app via
  universal links, and shows a plain page linking to RedCircle for everyone
  else.
- `/.well-known/apple-app-site-association` is what tells iOS the app may
  claim these links. Don't rename or move it.
